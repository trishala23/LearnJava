A quick map of where each covered version sits.

Java 8 2014

Lambdas, Streams, the java.time API, default interface methods — the release that made Java feel functional.

Java 11 2018 · LTS

var, a modern HttpClient, new String/Files convenience methods, single-file source launching.

Java 17 2021 · LTS

Sealed classes and text blocks become standard — stepping stones to Java 21's pattern matching.

Java 21 2023 · LTS

Record patterns, pattern matching for switch, virtual threads, and sequenced collections.

Java 25 2025 · Latest LTS

Compact source files, module imports, flexible constructor bodies, and finalized scoped values.
