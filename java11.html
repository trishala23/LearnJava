Java 11 Features

The first LTS after Java 8 — smaller, pragmatic quality-of-life upgrades rather than a paradigm shift.

1. Local Variable Type Inference (var)

Introduced in Java 10, extended to lambda parameters in Java 11. The compiler infers the type — var is not dynamic typing.

var name = "Duke";              // inferred: String
var list = new ArrayList<String>(); // inferred: ArrayList<String>
var total = 0;                    // inferred: int

for (var i = 0; i < 5; i++) { /* i is int */ }

// Java 11: var allowed in lambda parameters (to add annotations, e.g.)
list.forEach((var s) -> System.out.println(s));
Limits: var only works for local variables with an initializer — not for fields, method parameters (pre-11 style), or return types. var x; and var y = null; don't compile.

2. New String Methods

"  ".isBlank();          // true  (whitespace-only)
"".isEmpty();              // true  (length 0 — pre-existing)
"  hi  ".strip();          // "hi"  (Unicode-aware trim)
"  hi  ".stripLeading();   // "hi  "
"  hi  ".stripTrailing();  // "  hi"

"line1\nline2\nline3".lines().count(); // 3
"ab".repeat(3);                          // "ababab"

3. The Standard HttpClient

A modern, fluent HTTP client (incubated in 9, standardized in 11) replacing the clunky HttpURLConnection — with sync and async support, plus HTTP/2.

HttpClient client = HttpClient.newHttpClient();

HttpRequest request = HttpRequest.newBuilder()
    .uri(URI.create("https://api.example.com/users/1"))
    .GET()
    .build();

// Synchronous
HttpResponse<String> response =
    client.send(request, HttpResponse.BodyHandlers.ofString());
System.out.println(response.statusCode());

// Asynchronous
client.sendAsync(request, HttpResponse.BodyHandlers.ofString())
      .thenApply(HttpResponse::body)
      .thenAccept(System.out::println);

4. Single-File Source-Code Launching

Run a .java file directly — no separate javac step — great for scripts and quick experiments.

$ java Hello.java
Hello, Java!
Under the hood the source is compiled to memory and executed in one step; it's meant for single-file programs, not multi-class projects.

5. Files convenience methods

String content = Files.readString(Path.of("notes.txt"));
Files.writeString(Path.of("out.txt"), "Hello, file!");

// Also new in 11: Collection.toArray(IntFunction)
String[] arr = List.of("a", "b", "c").toArray(String[]::new);

6. What Was Removed

Java 11 dropped Java EE & CORBA modules that shipped with earlier JDKs (JAX-WS, JAXB, JAF, Common Annotations) — apps depending on them now need external Maven/Gradle dependencies.

Removed moduleReplacement
java.xml.bind (JAXB)org.glassfish.jaxb:jaxb-runtime
java.xml.ws (JAX-WS)com.sun.xml.ws:jaxws-ri
Java Web Start / javawsThird-party launchers (e.g. OpenWebStart)
