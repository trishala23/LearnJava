1. JVM, JRE & JDK

Java code compiles to bytecode, not machine code. The JVM interprets/JIT-compiles that bytecode — which is why "write once, run anywhere" works.

Compile → run: javac HelloWorld.java produces HelloWorld.class (bytecode); java HelloWorld hands that bytecode to the JVM.

3. Operators & Control Flow

Arithmetic, relational, logical, and bitwise operators combine with if/switch/loops to drive program logic.

int score = 82;
if (score >= 90) {
    System.out.println("A");
} else if (score >= 75) {
    System.out.println("B");
} else {
    System.out.println("C");
}

// Java 14+ switch expression
int day = 3;
String name = switch (day) {
    case 1, 7 -> "Weekend";
    case 2, 3, 4, 5, 6 -> "Weekday";
    default -> "Unknown";
};
System.out.println(name);

for (int i = 0; i < 3; i++) System.out.print(i);
int i = 0;
while (i < 3) { System.out.print(i); i++; }
for (int n : new int[]{1,2,3}) System.out.print(n);
Watch out: the old switch statement falls through without break. The Java 14+ arrow form (->) does not fall through.

4. Arrays

An array is a fixed-size, index-based container of elements of the same type. Once created, its length can never change.

int[] nums = {4, 8, 15, 16, 23, 42};
int[] empty = new int[5];        // all zeros — the default for int

System.out.println(nums.length); // 6 (a field, not a method — no parens)
System.out.println(nums[0]);      // 4
nums[0] = 100;                     // arrays are mutable, unlike Strings

for (int n : nums) System.out.print(n + " ");

    {1, 2, 3},
    {4, 5, 6}
};
System.out.println(grid[1][2]); // 6 — row 1, column 2
System.out.println(grid.length);    // 2 rows
System.out.println(grid[0].length); // 3 columns
import java.util.Arrays;

int[] a = {5, 3, 1, 4, 2};
Arrays.sort(a);                         // [1, 2, 3, 4, 5] — sorts in place
System.out.println(Arrays.toString(a));  // "[1, 2, 3, 4, 5]"
int[] copy = Arrays.copyOf(a, 3);         // [1, 2, 3]
boolean has = Arrays.asList(1, 2, 3).contains(2); // true
Common pitfall: accessing nums[nums.length] or any out-of-range index throws ArrayIndexOutOfBoundsException — valid indices run from 0 to length - 1.

5. Strings

String is Java's text type — and one of the most important classes to truly understand, because it behaves differently from most objects in two big ways: it's immutable, and literals are pooled.

Why immutable?

Every "modification" of a String (concatenation, substring, toUpperCase, …) returns a brand-new String — the original is never changed. This is deliberate:

  • Safety: Strings are used as map keys, file paths, class names, network hostnames — if they could mutate after being handed out, that would break assumptions everywhere.
  • Thread-safety for free: an immutable object can be shared across threads with no synchronization at all.
  • Caching works: a String can safely cache its own hashCode() the first time it's computed, since it can never change afterward.
  • Enables the String pool (below) — sharing would be unsafe if Strings were mutable.

String s = "  Hello, World!  ";

s.length();               // 17
s.trim();                  // "Hello, World!" (ASCII whitespace only)
s.strip();                 // "Hello, World!" (Unicode-aware, Java 11+)
s.toUpperCase();           // "  HELLO, WORLD!  "
s.substring(2, 7);         // "Hello"
s.indexOf("World");        // 9
s.replace("Hello", "Hi");  // "  Hi, World!  "
s.contains("World");        // true
s.split(",\\s*");           // ["  Hello", "World!  "]
s.charAt(2);                 // 'H'
"abc".compareTo("abd");      // negative — lexicographic comparison
"ABC".equalsIgnoreCase("abc"); // true
// String concatenation with + creates new objects each time —
// fine for a few, wasteful in a loop.
String result = "";
for (int i = 0; i < 5; i++) {
    result += i;              // rebuilds a new String every iteration
}

// StringBuilder mutates an internal buffer instead — much faster in loops.
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 5; i++) {
    sb.append(i);
}
System.out.println(sb.toString()); // "01234"

// StringBuffer has the identical API but is synchronized (thread-safe, slower) —
// prefer StringBuilder unless multiple threads truly share the same buffer.
String msg = String.format("%s is %d years old", "Duke", 30);
System.out.println(msg); // "Duke is 30 years old"

String joined = String.join(", ", "a", "b", "c"); // "a, b, c"

// Java 15+ text blocks for multi-line strings (see Java 21 page for more)
String html = """
    <p>Hello</p>
    """;
== vs .equals(): always compare String content with .equals() (or .equalsIgnoreCase()). == compares references, and only happens to "work" for literals because of pooling — it silently breaks the moment either side comes from new String(...), user input, or substring()/concatenation results.

6. Enums

An enum defines a fixed, type-safe set of named constants — safer than using raw ints or Strings to represent a closed set of options (like "MON" vs. a typo like "MOM").

enum Day { MON, TUE, WED, THU, FRI, SAT, SUN }

Day today = Day.WED;
System.out.println(today);         // WED
System.out.println(today.name());   // "WED"
System.out.println(today.ordinal()); // 2 — zero-based position

for (Day d : Day.values()) {         // iterate every constant
    System.out.print(d + " ");
}

enum Planet {
    MERCURY(3.3e23, 2.4e6),
    EARTH(5.97e24, 6.4e6),
    JUPITER(1.9e27, 7.1e7);

    private final double mass;   // kg
    private final double radius; // meters

    Planet(double mass, double radius) {   // enum constructors are always private
        this.mass = mass;
        this.radius = radius;
    }

    double surfaceGravity() {
        double G = 6.67300E-11;
        return G * mass / (radius * radius);
    }
}

System.out.println(Planet.EARTH.surfaceGravity()); // ~9.8
enum Status { PENDING, APPROVED, REJECTED }

Status status = Status.APPROVED;
String message = switch (status) {
    case PENDING  -> "Waiting for review";
    case APPROVED -> "You're good to go!";
    case REJECTED -> "Please resubmit";
};
System.out.println(message);
// No default needed — the compiler knows every enum constant is covered.
import java.util.EnumSet;
import java.util.EnumMap;

EnumSet<Day> weekend = EnumSet.of(Day.SAT, Day.SUN);
System.out.println(weekend.contains(Day.SAT)); // true

EnumMap<Day, String> schedule = new EnumMap<>(Day.class);
schedule.put(Day.MON, "Standup");
// Both are backed by arrays internally — much faster and more
// memory-efficient than a HashSet/HashMap of enum keys.
Enums are full classes: they can implement interfaces, have abstract methods overridden per-constant, and are the recommended way to write a thread-safe Singleton (enum Singleton { INSTANCE; }) since the JVM guarantees exactly one instance even under serialization or reflection.

7. Classes & Objects

A class is a blueprint — it defines what fields and behavior instances will have. An object is one instance of that blueprint, created at runtime with new and living on the heap.

class Dog {
    String name;     // instance field — each object gets its own copy
    int age;

    void bark() {
        System.out.println(name + " says Woof!");
    }
}

Dog d1 = new Dog();      // 1. allocate memory on the heap
d1.name = "Rex";           // 2. d1 is a reference variable pointing at it
d1.age = 3;

Dog d2 = new Dog();       // a completely separate object
d2.name = "Fido";

d1.bark();                  // "Rex says Woof!"
d2.bark();                  // "Fido says Woof!" — same class, independent state

class Dog {
    String name;
    int age;

    Dog() {                      // no-arg constructor
        this("Unnamed", 0);        // this(...) delegates to another constructor
    }

    Dog(String name, int age) {   // parameterized constructor
        this.name = name;          // `this.name` = field, `name` = parameter
        this.age = age;
    }
}

Dog d1 = new Dog();               // uses the no-arg constructor -> "Unnamed", 0
Dog d2 = new Dog("Rex", 3);        // uses the parameterized one

// If you don't write ANY constructor, Java silently supplies a no-arg
// default constructor. The moment you write one yourself, that free
// default constructor disappears — you'd need to add one back explicitly.
class Counter {
    static int totalCreated = 0;   // ONE copy, shared by every instance
    int id;                          // a separate copy per instance

    Counter() {
        totalCreated++;               // shared static field
        id = totalCreated;
    }

    static void printTotal() {         // static methods can't use `this`
        System.out.println("Created: " + totalCreated);
    }
}

new Counter(); new Counter(); new Counter();
Counter.printTotal();     // "Created: 3" — call static members on the class itself

class Point {
    int x, y;
    Point(int x, int y) { this.x = x; this.y = y; }

    @Override
    public String toString() { return "(" + x + ", " + y + ")"; }

    @Override
    public boolean equals(Object o) {
        if (!(o instanceof Point p)) return false;   // Java 16+ pattern instanceof
        return x == p.x && y == p.y;
    }

    @Override
    public int hashCode() { return Objects.hash(x, y); }
}

// Every class implicitly extends Object, which is where toString(),
// equals(), and hashCode() come from — the defaults print/compare by
// identity (memory address), which is rarely what you actually want.
Where objects live: the object itself is allocated on the heap; a reference variable like d1 lives on the stack (or as a field on another object) and just points at it. Assigning d2 = d1 copies the reference, not the object — both variables then point at the same Dog.
Garbage collection: once no reference anywhere in the program points to an object, it becomes eligible for collection — you never free() it manually. See Advanced Topics for how the collector actually finds and reclaims it.

8. Object-Oriented Programming

The four pillars: encapsulation, inheritance, polymorphism, abstraction.

public class Account {
    private double balance; // hidden state

    public Account(double balance) { this.balance = balance; }

    public void deposit(double amount) {
        if (amount > 0) balance += amount;
    }

    public double getBalance() { return balance; }
}
class Animal {
    void speak() { System.out.println("..."); }
}

class Dog extends Animal {          // Dog IS-A Animal
    @Override
    void speak() { System.out.println("Woof!"); }
}
Animal a = new Dog();
a.speak(); // "Woof!" — runtime (dynamic) polymorphism

// compile-time polymorphism: overloading
int add(int a, int b) { return a + b; }
double add(double a, double b) { return a + b; }

abstract class Shape {
    abstract double area();          // no body — subclass must implement
    void describe() { System.out.println("Area: " + area()); }
}

interface Drawable {                  // pure abstraction (Java 8+: can have default methods)
    void draw();
    default void highlight() { System.out.println("✨"); }
}

class Circle extends Shape implements Drawable {
    double radius;
    Circle(double r) { radius = r; }
    double area() { return Math.PI * radius * radius; }
    public void draw() { System.out.println("○"); }
}
abstract class vs interface: a class can extend only one abstract class but implement many interfaces; abstract classes may hold instance state, interfaces (pre-Java 9) may not.

9. Exception Handling

Exceptions separate error-handling from normal logic. Throwable splits into Error (JVM-level, don't catch) and Exception.

Throwable
↙↘
Error
OutOfMemoryError
Exception
checked / unchecked
try {
    int result = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println("Caught: " + e.getMessage());
} finally {
    System.out.println("Always runs");
}

class InsufficientFundsException extends Exception { // checked
    InsufficientFundsException(String msg) { super(msg); }
}
Checked vs unchecked: checked exceptions (e.g. IOException) must be declared or caught; unchecked (RuntimeException and its subclasses, e.g. NullPointerException) don't require that — and try-with-resources auto-closes any AutoCloseable.
try (BufferedReader r = new BufferedReader(new FileReader("f.txt"))) {
    System.out.println(r.readLine());
} catch (IOException e) {
    e.printStackTrace();
} // r.close() called automatically
